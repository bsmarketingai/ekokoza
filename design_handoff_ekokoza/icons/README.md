# Ikony — Hugeicons (outline, tah 1,5 px)

Sada obsahuje jen ikony, které finální design skutečně používá (152 ks). Zdroj: Hugeicons (podklady klienta).

**Použití:** jednobarevné SVG. V designu se barví přes CSS masku (`mask: url(icon.svg)` + `background-color`), aby dědily barvu. V kódu lze stejně, nebo inline SVG se `stroke="currentColor"`.

- Běžná velikost 18–24 px, v tlačítkách 18–20 px, v hlavičce 22–24 px.
- Barvy: tmavá zeleň `#4C653D` (výchozí), šedá `#7C7A6A` (ikony v polích), bílá na terrakotě, krémová `#F6F1E7` na tmavé zeleni.
- Bez stínů a výplní.
